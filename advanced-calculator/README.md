# Advanced Calculator

A modern calculator application built with React, Next.js, and TypeScript.

This project is the advanced version of the calculator in the Calculator Suite and uses a modern component-based frontend architecture.

## Technologies

* React
* Next.js
* TypeScript
* JavaScript
* CSS
* Node.js
* npm

## Project Structure

The application is organized into separate folders for application pages, reusable components, utilities, tests, and supporting functionality.

```text
advanced-calculator/
├── app/
├── components/
├── db/
├── drizzle/
├── hooks/
├── lib/
├── public/
├── scripts/
├── tests/
├── vendor/
├── worker/
├── package.json
├── package-lock.json
├── tsconfig.json
└── README.md
```

## Requirements

Before running the project, make sure you have Node.js and npm installed.

Check your installation with:

```bash
node --version
npm --version
```

## Installation

Clone the repository or download the project, then open a terminal inside:

```text
advanced-calculator
```

Install the required dependencies:

```bash
npm install
```

## Run the Application

Start the development server:

```bash
npm run dev
```

Then open the local address displayed in the terminal in your web browser.

For example:

```text
http://localhost:3000
```

The exact port may differ depending on the development environment.

## Testing

If the current project configuration includes tests, run:

```bash
npm test
```

## Build

To create a production build:

```bash
npm run build
```

## Important

The `node_modules` directory is not stored in GitHub.

After cloning the project, run:

```bash
npm install
```

to recreate all required dependencies.
