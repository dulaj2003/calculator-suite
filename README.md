# Calculator Suite

A collection of calculator applications built using different web technologies.

This repository contains two independent implementations of a calculator:

* **Simple Calculator** — HTML, CSS, and JavaScript
* **Advanced Calculator** — React, Next.js, and TypeScript

## Projects

### Simple Calculator

A lightweight calculator built with plain HTML, CSS, and JavaScript.

**Technologies**

* HTML5
* CSS3
* JavaScript

No installation or build process is required.

[View Simple Calculator](./simple-calculator)

---

### Advanced Calculator

A modern calculator application built using React, Next.js, and TypeScript.

**Technologies**

* React
* Next.js
* TypeScript
* Node.js

The project uses a modern frontend project structure and package-based development workflow.

[View Advanced Calculator](./advanced-calculator)

## Purpose

The purpose of this repository is to demonstrate two approaches to building a calculator application:

1. A simple implementation using core web technologies.
2. A more structured implementation using a modern React and TypeScript stack.
