# Simple Calculator

A lightweight calculator application built using HTML, CSS, and JavaScript.

This project does not require Node.js, npm, a framework, or a build process.

## Technologies

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
simple-calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

### Method 1 — Open Directly

1. Open the `simple-calculator` folder.
2. Double-click `index.html`.
3. The calculator will open in your default web browser.

No installation is required.

## Method 2 — VS Code Live Server

1. Open the `simple-calculator` folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The calculator will open in your web browser.
